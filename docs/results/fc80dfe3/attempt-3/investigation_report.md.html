5. Key Deductions

  1. Theft Window: Prototype removed between 18:00 (V02) and 18:18 (V05)

  2. Clock Offset Critical: Service camera shows +5 minute offset (D03, V10). Eli's "18:19" appearance is actually 18:14—within the theft window.

  3. Unmonitored Access: Service Corridor provides unmonitored link to lab (V01), allowing theft without triggering main cameras.

  4. Badge vs Identity: D03 notes doors log badge credentials, not biometric identity. However, coat colors match assigned identities consistently across all visual evidence.

  5. Single Point of Failure: Only Eli Stone has both opportunity (service door access during theft window) and direct visual evidence of possession (V04).
