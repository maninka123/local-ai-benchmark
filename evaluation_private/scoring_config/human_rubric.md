# Fixed independent review rubric v1.0

Review a randomly assigned attempt ID with model identity hidden. Do not read the speed table until quality review is finished. Do not ask the candidate to score itself. Use a second independent reviewer when available; retain each review separately and document disagreements. No external or paid judge is configured.

Award 0 for absent/nonfunctional evidence; 25% for a small working subset; 50% for roughly half the requested behavior supported by observations; 75% for most requirements with meaningful limitations; 100% only when the entire criterion is supported. Use the precise task category maxima in the score JSON. Provide concrete artifact names and observations for every correction, especially nonzero subjective scores. Do not infer implementation from comments, hooks or the implementation report alone.

## Data

Data understanding/cleaning (15): all six tables described, keys/dtypes checked, dirty data decisions disclosed and justified, mathematical relationships verified. Numerical accuracy (20): reconcile supplied metrics with private reference; evaluate defensible alternate cleaning rules rather than blindly enforcing one recipe. Hidden patterns (20): credit only numerical, source-linked discoveries; no keyword-only credit. Visualization (15): six distinct readable meaningful figures, executable source uses actual table values, correct labels/units/scales, report interprets each. Report (15): approximately 2,000 words, required sections, clear coherent factual prose and appropriate limits. Recommendations (15): supported by quantitative findings, prioritized and feasible; association and causal inference distinguished.

## Game

Build/execution (15): actual implemented game, successful build and browser render, no critical errors. Driving (15): both key schemes, acceleration/braking/reverse/friction, steering and speed dependence visibly affect position. NPC intelligence (20): four opponents navigate track, regulate corner speed, react to cars/obstacles, recover after displacement, finish laps; capture lap/collision/stuck/recovery observations independently. Collisions (15): test car-car, barrier and scenery contacts, visible response and recovery. Cameras/UI (10): three distinct usable views, full menu/selection/HUD/pause/results/controls. Race mechanics (10): countdown, three laps, ordered checkpoint validation, timings/position/finish/restart; deliberately skip checkpoints and verify no lap is granted. Visual quality (10): deliberate procedural cars, track/scenery, lighting/shadows, road markings and clear UI; judge standardized screenshots. Robustness (5): inspect architecture, bounded update steps, resizing, pause/restart repeated inputs and error recovery. Completion may be marked true only after independent driving, collision, checkpoint and NPC finish verification.

## Detective

Events (25): reconstruct chronological true events with linked exhibits and clock correction where necessary; distinguish observed and inferred intervals. Visual evidence (20): compare each of ten observations against private visual fact map; no invented objects/identities. Logic (20): conclusion follows evidence with alternatives considered, appearance is not treated as biometric identity, motive is not proof. Evidence accuracy (15): factual exhibit citations, contradiction resolution, no invented exhibits or witness certainty. Uncertainty (10): ambiguous case abstains and specifies needed evidence; identified cases state appropriate qualification. Report (10): complete nine-section clear professional investigation with evidence inventory, suspect analysis, limitations and next steps. Deduct for fabricated observations, unsupported certainty or contradictions, with explicit evidence and rationale; never produce negative category points.

Original automatic scores are immutable. Use the local review API to append reviewer identity, all corrected categories, observed completion and reason. The original and effective results remain inspectable; speed metrics must never be changed by a quality reviewer.
